# กราฟชีวิตและเลขเจ็ดตัว 9 ฐาน — V9.5 ฉบับปรับปรุง

ฐานของรุ่นนี้คือ `promyan_wt_tuksa9.4.html` ไม่ใช่ SevenStar-9Base V1.15
คะแนนประเมิน SevenStar ก่อนหน้านี้ไม่ใช่คะแนนของระบบนี้

ฉบับนี้ลบป้ายระดับไพ่ที่บังภาพ เพิ่มการยืนยัน Google Sheet และรันชุด UI จริงแล้ว
การบันทึก Google Sheet ต้องอัปเดต Apps Script เพิ่มตาม `google-apps-script/SETUP.md` ก่อน
ขณะนี้ยังไม่ได้ Deploy ในบัญชี Google ของหมอโย และไม่ส่งข้อมูลจริงเพื่อทดสอบ

## ติดตั้งเพื่อใช้งาน

1. สำรองไฟล์ V9.4 ไว้ก่อน
2. วาง `promyan_wt_tuksa9.5.html` ในโฟลเดอร์เดียวกับโฟลเดอร์ `images` เดิม
3. เปิดไฟล์ V9.5 ในเว็บเบราว์เซอร์บนโน้ตบุ๊ก/เดสก์ท็อป
4. หากหน้าเว็บเดิมใช้ชื่อ `index.html` ให้สำรองไฟล์นั้น แล้วใช้ HTML รุ่นนี้เป็น `index.html`

ZIP นี้ไม่มีภาพไพ่ เพราะไฟล์ต้นฉบับที่ได้รับไม่มีโฟลเดอร์ `images` แนบมาด้วย
อย่าย้าย HTML ไปอยู่ภายใน `images` และไม่ต้องลบภาพเดิม
ยังใช้ฟอนต์ Google Fonts และ html2canvas จาก CDN ตามระบบเดิม จึงไม่ได้รับรองการใช้งานออฟไลน์ทั้งหมด
ไม่ได้อัปโหลดหรือเปลี่ยนเว็บไซต์จริงให้โดยอัตโนมัติ

Code.gs ปรับตามโค้ดเดิมแล้ว: ใช้ A–D เดิม เพิ่ม E=request_id และ F=saved_at
ต้องตั้ง SPREADSHEET_ID และ SHEET_NAME ทั้งสองค่า และเตรียมหัวคอลัมน์ก่อน Deploy

## Accessibility ที่เพิ่ม

- เชื่อม label กับช่องกรอกและแจ้งข้อผิดพลาดพร้อมย้ายโฟกัสไปช่องที่ขาด
- เพิ่มลิงก์ข้ามเนื้อหา หัวข้อหลัก และชื่อพื้นที่แผนผังที่เลื่อนด้วยคีย์บอร์ดได้
- ไพ่ที่กดได้รองรับ Enter/Space พร้อมชื่อ ตำแหน่ง ระดับไพ่ และ aria-pressed
- คืนโฟกัสเมื่อเปลี่ยนอายุแล้วสร้างกระดานใหม่ และเมื่อสลับเข้า/ออกหน้าฐานกราฟ 12 ใบ
- แสดงเส้นโฟกัสชัดเจน รองรับ reduced motion และ forced colors
- ลบป้ายระดับไพ่บนภาพตามคำขอ คงคำอธิบายระดับไว้ใน aria-label สำหรับ Screen Reader
- เพิ่มข้อความอ่านได้ของศรี/กาลี/อายุ และคำอธิบายจุดเตือน Timeline
- การ์ดคะแนนมี meter semantics พร้อมคะแนนและระดับ
- เพิ่ม alt ของรูปไพ่ ชื่อช่องข้อมูลเจ้าชะตา และชื่อ Dropdown ตัวเลขกราฟที่ยังใช้งาน
- ปรับตัวหนังสือคะแนน/ปัจจัยให้เข้มขึ้น และเพิ่มขนาดรายละเอียดการ์ดคะแนน
- แจ้งสถานะขณะสร้างภาพ ป้องกันกดส่งออกกระดานหลักซ้ำ และคืนช่องกรอกหลังส่งออกล้มเหลว
- ป้องกันการโหลดภาพสำรองวนไม่สิ้นสุดเมื่อไม่มี images/back.jpg

ยังไม่ใช่การรับรอง WCAG: ต้องตรวจ contrast ทุกสถานะ, NVDA/Screen Reader, การซูม และภาพจริงเพิ่มเติม
การจัดหน้ากระดานสองมิติยังใช้การเลื่อนแนวนอนตามลักษณะระบบ ไม่ได้ออกแบบหน้ามือถือใหม่

## รันชุดทดสอบบน Windows

ต้องมี Node.js รุ่นที่รองรับ Playwright และ npm ก่อน จากนั้นเปิด Terminal ในโฟลเดอร์ที่แตก ZIP:

```powershell
npm install
npx playwright install chromium
npm test
npm run test:ui
npm run test:report
```

| คำสั่ง | ตรวจอะไร |
|---|---|
| `npm test` | 20 ชุดตรวจโค้ด/สูตร/การยืนยันบันทึก รวมข้อมูลตั้งต้น 1,008 ชุด |
| `npm run test:ui` | 27 สถานการณ์ × 2 ขนาดจอ รวม 54 รายการ |
| `npm run test:report` | เปิดรายงาน UI หลังรันจริง |

ทดสอบจอ 1366×768 และ 1920×1080 บน Chromium เท่านั้น ไม่ใช่การรับรอง Safari/Firefox/Edge ทุกเวอร์ชัน
ชุด UI ใช้ภาพไพ่จำลองและคำตอบ Google Sheet จำลอง ไม่มีการส่งข้อมูลจริง
การทดสอบลำดับ UI ใช้ตัวสร้างภาพจำลอง ส่วน `export-real.spec.cjs` ใช้ html2canvas 1.4.1 จริง
ตรวจการดาวน์โหลด PNG, รูปแบบไฟล์ และขนาดภาพ ทั้งหน้าเลข 7 ตัวและฐานกราฟ12ใบ
ยังไม่ยืนยันภาพไพ่ต้นฉบับหรือความพร้อม CDN จริง
รายงาน Playwright ที่รันแล้วอยู่ใน `playwright-report` เปิดด้วย `npm run test:report`

## ตรวจรับเพิ่มเติมด้วยไฟล์ภาพจริง

| รายการ | ผลที่ต้องได้ |
|---|---|
| กรอกข้อมูลและประมวลผล | แผนผังเหมือน V9.4 สำหรับข้อมูลเดียวกัน |
| โหมดเลข 7 ตัว | การ์ดคะแนนครบ 7 ใบ ไม่มี Dropdown 22 หัวข้อ |
| Enter/Space บนไพ่ | ทำงานเหมือนคลิกเมาส์ โฟกัสเห็นชัด |
| เปลี่ยนอายุ | ชื่อ/ข้อมูลประกอบ/เลขกำกับไม่หาย และโฟกัสไม่กระโดดไปต้นหน้า |
| ฐานกราฟ12ใบ | เปิด/กลับหน้าหลักและเลือกอายุด้วยคีย์บอร์ดได้ |
| บันทึก PNG ทั้งสองหน้า | ภาพไพ่จริง ฟอนต์ ไฮไลต์ และข้อความไม่ถูกตัด |
| ซูม 200% และ 400% | เข้าถึงทุกปุ่ม/ข้อมูลด้วยการเลื่อน ไม่มีโฟกัสถูกบัง |
| NVDA หรือ Screen Reader | อ่านชื่อช่อง ไพ่ คะแนน และการเปลี่ยนสถานะได้ |

ดูผลตรวจที่ทำจริงและข้อจำกัดใน `TEST_REPORT.md`

# V9.5 — ตั้งค่า Login และล็อกการบันทึก

หน้าเว็บใช้ URL GitHub Pages เดิม ภาพเศียรครูอยู่ซ้าย กล่อง Login อยู่ขวา หลังเข้าใช้งานเป็นกระดานเดิม เพิ่มปุ่มออกจากระบบด้านบน

## 1. ตั้งบัญชีใน GAS

เปิดโปรเจกต์ Apps Script **ตัวที่ใช้บันทึกอยู่แล้ว** และสำรอง Code.gs เดิมไว้ในเครื่อง จากนั้นแทน Code.gs ทั้งหมดด้วยไฟล์ในชุดนี้ (มีโค้ดแฮชรวมอยู่ท้ายไฟล์แล้ว ไม่ต้องติดตั้ง Library เพิ่ม)

ค้นหาบรรทัดต้นไฟล์ในฟังก์ชัน `setupOwnerAccount`:

```js
var USERNAME = ''; // ใส่ชื่อผู้ใช้ระหว่างเครื่องหมายคำพูด
var PASSWORD = ''; // ใส่รหัสผ่านระหว่างเครื่องหมายคำพูด
```

| ค่า | ข้อกำหนด |
|---|---|
| USERNAME | 3–64 ตัวอักษร ตัวพิมพ์ใหญ่/เล็กมีผล ตัดช่องว่างหัวท้าย |
| PASSWORD | 15–128 ตัวอักษร ตัวพิมพ์ใหญ่/เล็กและช่องว่างมีผล ใช้รหัสเฉพาะเว็บนี้ |

หากรหัสมีเครื่องหมาย `'` หรือ `\` ต้อง escape ให้ถูกตาม JavaScript; เพื่อกรอกง่ายสามารถใช้ตัวอักษร ตัวเลข และเครื่องหมายอื่นแทน

1. กรอกค่าจริง **ใน Apps Script ของคุณเท่านั้น** ไม่ต้องส่งรหัสผ่านให้ AI
2. กด Save
3. เลือกฟังก์ชัน `setupOwnerAccount` จากรายการข้างปุ่ม Run แล้วกด **Run / เรียกใช้**
4. อนุญาตสิทธิ์ถ้า Google ถาม รอจน execution สำเร็จ ฟังก์ชันนี้ไม่เพิ่มแถวใน Sheet
5. ลบค่าจริงทั้งสองกลับเป็น `''` แล้ว Save อีกครั้ง **ก่อน Deploy และก่อนนำไฟล์ใดขึ้น GitHub**

ระบบเก็บชื่อผู้ใช้, salt และค่าแฮช PBKDF2-HMAC-SHA256 600,000 รอบใน Script Properties ชื่อ `PROMYAN_OWNER_V1` โดยอัตโนมัติ ไม่มีรหัสผ่านตรง ๆ ในค่านี้ ไม่ต้องแก้ JSON เอง

รหัสที่เคยกรอกอาจยังมีในประวัติแก้ไขโปรเจกต์ GAS ผู้มีสิทธิ์แก้ไขโปรเจกต์จึงต้องเป็นบุคคลที่คุณไว้วางใจ และอย่าใช้รหัสบัญชี Google ของคุณ

## 2. คงค่า Sheet เดิม

| Script Property | ค่า |
|---|---|
| SPREADSHEET_ID | ID ของไฟล์ Google Sheet เดิม |
| SHEET_NAME | `Sheet1` หรือชื่อแท็บที่ใช้จริง |

ฟังก์ชันตั้งบัญชีไม่แก้สองค่านี้และไม่แตะข้อมูลใน Sheet

คอลัมน์ A–D เดิมคงเดิม; E1 ต้องเป็น `request_id`; F1 ต้องเป็น `saved_at` ระบบไม่เขียนทับหัวตารางอัตโนมัติ Google Sheet คง General access เป็น Restricted

## 3. อัปเดต Deployment เดิม

| ขั้นตอน | ทำอย่างไร |
|---|---|
| เปิด Deployment | Deploy → Manage deployments |
| แก้ตัวเดิม | เลือก Web app เดิม → รูปดินสอ |
| เวอร์ชัน | Version → **New version** |
| Execute as | **Me** |
| Who has access | **Anyone** — เพื่อรับคำขอจาก GitHub; Code.gs เป็นผู้ตรวจ Username/Password และสิทธิ์ก่อนบันทึก |
| ใช้งาน | กด Deploy |

**อย่าเปลี่ยนเป็น Only myself ในแนวทางนี้** เพราะหน้า GitHub ใช้การ Login ของระบบเราเอง ไม่ได้ส่ง Google session ไปกับ fetch

อัปเดต deployment เดิมจะคง URL `/exec` เดิม HTML ชุดนี้ตั้ง URL เป็นปลายทางที่คุณให้ไว้แล้ว หากสร้าง deployment ใหม่ต้องเปลี่ยน `DATABASE_URL` ใน HTML ให้ตรงกัน

หากมี Web app deployment อื่นที่ยังใช้ Code.gs รุ่นเดิมไม่มี Login ให้ **Archive deployment เก่าที่ไม่ใช้งาน** หรืออัปเดตให้ตรวจสิทธิ์ด้วย มิฉะนั้นยังส่งข้อมูลผ่าน URL เก่าได้ การสร้างเวอร์ชันใหม่เพียงอย่างเดียวโดยไม่เปลี่ยน deployment ไม่พอ

ตรวจ URL GAS `/exec?action=health` (ไม่ใช่ URL GitHub) ควรได้:

```json
{"protocol":"promyan-save-v1","ok":true,"ready":true,"authRequired":true}
```

| อาการ | ความหมาย/วิธีแก้ |
|---|---|
| AUTH_NOT_CONFIGURED | ยังไม่รัน setupOwnerAccount หรือค่าบัญชีไม่สมบูรณ์ |
| NOT_CONFIGURED | ขาด SPREADSHEET_ID หรือ SHEET_NAME |
| SHEET_NOT_FOUND | ชื่อแท็บไม่ตรง |
| SCHEMA_MISMATCH | ตรวจ E1/F1 ห้ามเขียนทับข้อมูลอื่นโดยไม่สำรอง |
| ไม่มี authRequired:true | ยังเรียก deployment โค้ดเก่า |

อัปโหลดสองรายการนี้ใน repository `Life-Graph-Cards`:

| ไฟล์ใน ZIP | ตำแหน่งบน GitHub |
|---|---|

| assets/login-teacher.jpg | โฟลเดอร์ assets ที่ root |

**เก็บโฟลเดอร์ images ของไพ่เดิมไว้ทั้งหมด** ZIP นี้ไม่มีภาพไพ่เดิมและไม่ใช่คำสั่งให้ล้าง repository

ไฟล์ `google-apps-script/Code.gs` นำไปวางใน Apps Script; ไม่จำเป็นต้องอัปโหลดไฟล์ GAS คู่มือ หรือ tests ขึ้นเว็บไซต์ โดยเฉพาะไฟล์ที่คุณเคยใส่รหัสจริง

รอ GitHub Pages deploy แล้วเปิด URL เดิม กด Ctrl+Shift+R เพื่อโหลดฉบับใหม่

## 5. ทดสอบจริงหลังติดตั้ง

| การทดสอบ | ผลที่ควรได้ |
|---|---|
| เปิด URL เดิม | เห็นภาพจริงกับกล่อง Login ด้านขวา ไม่เห็นกระดานก่อนเข้าใช้งาน |
| ใส่รหัสผิด | แจ้งชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง ยังไม่เปิดกระดาน |
| ใส่ค่าที่ตั้งใน GAS | เปิดกระดานเดิม |
| ประมวลผล กราฟชีวิต เลข7ตัว ฐานกราฟ12ใบ | ทำงานเหมือนเดิม |
| บันทึก PNG | ภาพไม่มีหน้า Login และไม่มีแถบออกจากระบบ |
| บันทึก Sheet | มีแถวใหม่และข้อความยืนยัน row/request_id |
| กดบันทึกข้อมูลเดิมซ้ำในแท็บเดิม | แจ้งรายการบันทึกแล้ว ไม่มีแถวเพิ่ม |
| Refresh ขณะสิทธิ์ยังใช้ได้ | ตรวจสิทธิ์กับ GAS แล้วเปิดกระดาน โดยข้อมูลแบบฟอร์มทำงานตามการ refresh เดิม |
| Logout แล้วเปิด/refresh | ต้อง Login ใหม่ |
| เปิดหน้าต่างไม่ระบุตัวตน | ต้อง Login และไม่มีสิทธิ์บันทึกหากไม่มีรหัส |

ชุดทดสอบที่แนบใช้ข้อมูลจำลอง ไม่ได้เขียนลง Google Sheet จริงของคุณ ต้องทำตารางนี้ยืนยันหลัง deploy

## พฤติกรรมบัญชี

- อายุสิทธิ์ 8 ชั่วโมงนับจาก Login ไม่ยืดเวลาทุกครั้งที่กดใช้งาน
- อนุญาตหนึ่ง session ที่ใช้งานได้ในแต่ละช่วง Login ใหม่จะยกเลิกสิทธิ์ครั้งก่อน แท็บเดิมจะตรวจพบเมื่อติดต่อ GAS หรือเมื่อครบอายุ
- สิทธิ์เก็บใน sessionStorage ของแท็บ ไม่มีการเก็บรหัสผ่านใน localStorage/sessionStorage
- เบราว์เซอร์บางตัวอาจคืน sessionStorage เมื่อกู้คืนแท็บ จึงควรกดออกจากระบบเมื่อเลิกใช้
- การ Login ต้องต่ออินเทอร์เน็ต แม้สูตรเดิมคำนวณในเครื่องได้
- ลองผิดครบ 5 ครั้งในช่วง 15 นาทีจะพัก Login จนจบช่วงนั้น เปลี่ยน username ก็ไม่ข้ามขีดจำกัด นี่เป็นขีดจำกัดรวมของบัญชีเดียว อาจมีคนจงใจทำให้เจ้าของต้องรอได้
- การออกจากระบบที่สำเร็จจะยกเลิกสิทธิ์ฝั่ง GAS ล้างฟอร์มด้วยการ reload และล้าง request_id ค้างของแท็บ
- หากเครือข่ายขัดข้องตอน Logout จะปิดกระดานและแจ้งว่ายังยืนยันการยกเลิกบนเซิร์ฟเวอร์ไม่ได้ สิทธิ์เดิมหมดอายุภายใน 8 ชั่วโมง หรือเจ้าของรัน `revokeOwnerSessions` ใน editor เพื่อยกเลิกทันที
- หากสิทธิ์หมดอายุระหว่างกรอกหรือบันทึก ระบบเก็บฟอร์มและ request_id เดิมไว้ ให้ Login ใหม่แล้วกดบันทึกเอง ไม่มีการบันทึกอัตโนมัติ
- กันบันทึกซ้ำตาม request_id ของคำขอเดิม ไม่ใช่การห้ามข้อมูลชื่อ/วันเกิดเดียวกันตลอดไป และไม่ครอบคลุมการสร้างคำขอใหม่จากคนละแท็บ

## เปลี่ยนรหัสหรือลืมรหัส

กรอกค่าใหม่ใน `setupOwnerAccount` แล้ว Run อีกครั้ง ลบค่ากลับเป็น `''` แล้ว Save บัญชีใหม่ใช้ได้ทันทีผ่าน Script Properties; session เดิมถูกยกเลิก ควร deploy เวอร์ชันที่ลบรหัสออกแล้วหากเคย deploy ขณะมีค่าจริง

หากต้องการยกเลิกสิทธิ์ทั้งหมดอย่างเดียว เลือก `revokeOwnerSessions` แล้ว Run ใน Apps Script editor ไม่ต้องเปลี่ยนสูตรหรือข้อมูลใน Sheet

## ขอบเขตที่ตกลง

หน้า Login เป็นประตูสำหรับผู้ใช้ทั่วไปบนเว็บไซต์สาธารณะ ไฟล์ HTML/JavaScript/ภาพที่เผยแพร่ยังดาวน์โหลดได้ ผู้รู้วิธีแก้โค้ดอาจข้ามหน้าจอได้ แต่ GAS ตรวจสิทธิ์จริงทุกครั้งที่บันทึก รหัสผ่านที่กรอกผ่าน HTTPS ไม่อยู่ใน URL และระบบไม่ log รหัสหรือ token

นี่เป็นระบบบัญชีส่วนบุคคลใน GAS ไม่ใช่บริการพิสูจน์ตัวตนระดับองค์กร ไม่มี MFA หรือระบบกู้คืนรหัสทางอีเมล ต้องรักษาสิทธิ์แก้ไข GitHub/GAS และบัญชี Google ของเจ้าของ การจำกัด Login ไม่ป้องกันการยิงคำขอให้โควตา Apps Script หมด
